The token set.

Two tiers: primitives (the raw palette) resolve into semantic tokens (what product code actually references). Every semantic token carries a light and a dark value, so a single reference switches themes. Names map 1:1 to CSS custom properties and iOS asset/enum names — see the mapping at the end.

03 · Course cartography

The terrain itself

A separate layer from overlay chrome: these colour the SVG feature shapes drawn on the map — fairways, greens, bunkers, hazards. Each feature has three roles: fill (the polygon), draw (its active/being-drawn state in the builder), and outline (the stroke).

Your source palette was adapted — chroma pulled down ~25–35% and hues warmed toward the earthy system — so the map reads as calm Scandinavian cartography rather than saturated turf, while staying unmistakably golf. Where a feature maps to an existing brand token, it's noted.

07 · Motion

Calm, exact, no bounce

Chrome moves fast and gets out of the way; panels ease in gently; the map camera glides. Nothing overshoots. On-course animation shortens or drops entirely under prefers-reduced-motion and glance conditions.

Duration

--dur-instant80ms · toggles, presses
--dur-fast140ms · chrome, hovers
--dur-base220ms · panels, sheets
--dur-slow320ms · large surfaces
--dur-map480ms · camera pan / zoom

Easing

--ease-standard(.2,0,0,1)
--ease-out(.16,1,.3,1)
--ease-in-out(.65,0,.35,1)
--ease-map(.4,0,.1,1)

No spring/bounce curves anywhere — precision instruments don't wobble.

09 · Implementation

Web + iOS, one source of truth

Author tokens once in a platform-neutral form (color.text.primary), then generate CSS custom properties and an iOS asset catalog + Swift enums. Semantic names are identical across platforms — only the casing convention differs.

web · tokens.css
:root {
  /* text */
  --color-text-primary:   #211D14;
  --color-text-secondary: #55503F;
  --color-text-tertiary:  #8B8471;
  /* surface */
  --color-surface-app:    #F6F1E7;
  --color-surface-card:   #FBF8F1;
  /* accent */
  --color-accent-primary: #BF6A3E;
  --color-on-accent:      #FBF3E8;
  /* scales */
  --space-3: 12px;  --space-4: 16px;
  --radius-md: 12px; --radius-lg: 16px;
  --dur-base: 220ms;
  --ease-out: cubic-bezier(.16,1,.3,1);
}
[data-theme="dark"] {
  --color-text-primary:   #F1EADB;
  --color-surface-app:    #16130D;
  --color-surface-card:   #221D15;
  --color-accent-primary: #D2793F;
  --color-on-accent:      #1C130B;
}
iOS · Tokens.swift
// colours from asset catalog
// (Any + Dark appearances)
extension Color {
  static let textPrimary   = Color("text/primary")
  static let surfaceApp     = Color("surface/app")
  static let accentPrimary = Color("accent/primary")
  static let onAccent       = Color("on/accent")
}
enum Space {
  static let s3: CGFloat = 12
  static let s4: CGFloat = 16
}
enum Radius {
  static let md: CGFloat = 12
  static let lg: CGFloat = 16
}
enum Motion {
  static let base = Animation
    .timingCurve(0.16, 1, 0.3, 1,
                 duration: 0.22)
}

Theme switching: web toggles [data-theme] on <html>; iOS uses asset-catalog Any/Dark appearances so Color.textPrimary resolves automatically. The map-overlay tokens are the exception — because they sit on imagery, keep them identical across platforms as explicit rgba values rather than system-managed colours.
